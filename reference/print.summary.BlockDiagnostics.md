# Print the summary of a BlockDiagnostics object

Print the summary of a BlockDiagnostics object

## Usage

``` r
# S3 method for class 'summary.BlockDiagnostics'
print(x, ...)
```

## Arguments

- x:

  A `summary.BlockDiagnostics` object, as returned by
  [`summary()`](https://rdrr.io/r/base/summary.html) on a
  `BlockDiagnostics`.

- ...:

  Ignored.

## Value

The object, invisibly.
