# Print the summary of a CMOResult object

Print the summary of a CMOResult object

## Usage

``` r
# S3 method for class 'summary.CMOResult'
print(x, ...)
```

## Arguments

- x:

  A `summary.CMOResult` object, as returned by
  [`summary()`](https://rdrr.io/r/base/summary.html) on a `CMOResult`.

- ...:

  Ignored.

## Value

The object, invisibly.
