# Print the summary of a EvidenceEdge object

Print the summary of a EvidenceEdge object

``` r
# S3 method for class 'summary.EvidenceEdge'
print(x, ...)
```

## Arguments

- x:

  A `summary.EvidenceEdge` object, as returned by
  [`summary()`](https://rdrr.io/r/base/summary.html) on a
  `EvidenceEdge`.

- ...:

  Ignored.

## Value

The object, invisibly.
