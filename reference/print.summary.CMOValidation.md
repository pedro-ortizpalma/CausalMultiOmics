# Print the summary of a CMOValidation object

Print the summary of a CMOValidation object

``` r
# S3 method for class 'summary.CMOValidation'
print(x, ...)
```

- x:

  A `summary.CMOValidation` object, as returned by
  [`summary()`](https://rdrr.io/r/base/summary.html) on a
  `CMOValidation`.

- ...:

  Ignored.
