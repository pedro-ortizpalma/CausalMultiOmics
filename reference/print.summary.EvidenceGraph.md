# Print the summary of a EvidenceGraph object

Print the summary of a EvidenceGraph object

## Usage

``` r
# S3 method for class 'summary.EvidenceGraph'
print(x, ...)
```

## Arguments

- x:

  A `summary.EvidenceGraph` object, as returned by
  [`summary()`](https://rdrr.io/r/base/summary.html) on a
  `EvidenceGraph`.

- ...:

  Ignored.

## Value

The object, invisibly.
