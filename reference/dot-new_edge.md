# Build one EvidenceEdge

Build one EvidenceEdge

## Usage

``` r
.new_edge(
  source,
  target,
  estimate,
  generator,
  method,
  quantity = NA_character_,
  se = NA_real_,
  p_value = NA_real_,
  n = NA_integer_,
  ci = c(NA_real_, NA_real_),
  identification = "none",
  adjustment_set = character(),
  assumptions = character(),
  temporal = NA,
  source_block = NA_character_,
  target_block = NA_character_,
  effect_size = NA_real_,
  notes = character()
)
```
